# Weston Tech Portfolio (Version 1)

Plain HTML, CSS and vanilla JavaScript. No build step: open `index.html` or host on GitHub Pages.

- Projects: edit the `projects` array at the top of `js/script.js`. Filters appear automatically when projects span more than one category. Add `demo` only when a real deployment exists.
- Skills, journey: edit the lists in `index.html`.
- CV: add `assets/Weston-CV.pdf` (the Download CV button already points to it).
- Contact form only validates input. Connect an email service before treating it as a working form.
